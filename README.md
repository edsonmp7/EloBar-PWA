# Elo Bar — Android PWA

Repositório público exclusivo da Casca Android PWA do Elo Bar.

Este repositório contém somente a camada cliente instalável (HTML/CSS/JS, manifest, Service Worker e assets visuais). A lógica de negócio e o código do Elo Bar permanecem no repositório privado `edsonmp7/EloBar` e no Google Apps Script.

A Casca aponta para o Web App oficial de produção do Elo Bar e não armazena nem confirma operações de negócio por conta própria.
