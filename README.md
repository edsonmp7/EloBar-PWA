# Elo Bar — Android PWA

Repositório público exclusivo da Casca Android do Elo Bar.

Este repositório contém somente a camada cliente instalável e o wrapper Android nativo. A lógica de negócio e o código do Elo Bar permanecem no repositório privado `edsonmp7/EloBar` e no Google Apps Script.

## Camadas

- PWA pública: `https://edsonmp7.github.io/EloBar-PWA/`
- Projeto Android Studio: pasta `android/`
- Package Android: `com.eloclub.elobar`

A Casca aponta para o Web App oficial de produção do Elo Bar e não armazena nem confirma operações de negócio por conta própria.
